G.A.S.S. portfolio - exported site

1. Preview: open index.html in a browser (keep the media/ folder next to it).
2. Publish: drag this whole folder onto a static host (Netlify Drop, Cloudflare Pages, GitHub Pages...).
3. Before going live, open index.html and update CONTACT (email, Instagram, LinkedIn), and add an about.html page.
4. New media later: put the files in media/ and list them in the MEDIA object at the top of the script.
